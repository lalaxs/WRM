# Compact Vertical Combat Unit Cards Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the current minimal team unit blocks with four-across vertical combat cards that use the game's existing avatar renderer and visual language.

**Architecture:** Extend the immutable team combat snapshot with display-safe realm, identity, rank, and technique metadata; make the engine maintain the cooldown and last-trigger state that the card visualizes; map those fields through the public combat query; then render a stable DOM card grid in `ui.js` and theme it in `styles.css`. NPC configuration remains read-only and snapshot-based, with no NPC inventory or loadout mutation from the UI.

**Tech Stack:** Browser JavaScript (UMD modules), DOM/CSS, Canvas avatar renderer, Node selftests, release mirror script.

## Global Constraints

- Enemy cards are above the battlefield and ally cards are below it.
- Each faction uses a fixed four-column row; one to three units do not enlarge.
- Cards are vertical; the avatar is a small square identification window, not full-card art.
- Realm is in the card's top strip; name is overlaid at the bottom of the avatar.
- Cards show HP, optional Qi, action progress, and up to three technique slots.
- Cards do not show damage, healing, damage taken, threat, affection efficiency, or persistent Buff/Debuff text lists.
- Critical incapacitation may use a temporary avatar overlay.
- NPC techniques and equipment stay fixed and read-only; no real NPC inventory is introduced.
- Use the existing `--panel`, `--line`, `--primary`, `--mint`, `--pink`, `--danger`, and `--blue` palette.
- Validate fixed four-card rows at 375, 390, and 430 CSS pixels.

- `core/team-combat-snapshot.js`: produce immutable combat units with realm, identity, rank, and display-ready technique metadata.
- `core/team-combat-engine.js`: maintain per-technique cooldowns, Qi payment, and last-trigger markers.

- `selftest_team_combat_ui.js`: verify the public combat view fields.
- `selftest_team_combat_card_ui.js`: exercise the real card component against a lightweight DOM.

- [ ] **Step 3: Implement cooldown ticking and readiness**

Add helpers:

```js
function tickTechniqueCooldowns(unit) {
  Object.keys(unit.cooldowns || {}).forEach(function (techniqueId) {
    const remaining = Math.max(0, Number(unit.cooldowns[techniqueId]) || 0);
    unit.cooldowns[techniqueId] = Math.max(0, remaining - 1);
  });
}

function techniqueReady(actor, technique) {
  const remaining = Number(actor.cooldowns &&
    actor.cooldowns[technique.techniqueId]) || 0;
  const cost = Math.max(0, Number(technique.qiCost) || 0);
  return remaining <= 0 && (Number(actor.qi) || 0) >= cost;
}
```

Filter the candidate list in `act` with both `conditionMet` and `techniqueReady`. After `executeTechnique` succeeds:

```js
const cost = Math.max(0, Number(technique.qiCost) || 0);
actor.qi = Math.max(0, actor.qi - cost);
actor.cooldowns[technique.techniqueId] = Math.max(
  0,
  Number(technique.cooldownTicks) || 0
);
actor.lastTechniqueId = technique.techniqueId;
actor.lastTechniqueTick = session.elapsedTicks;
actor.cooldownTicks = actor.actionIntervalTicks;
```

Call `tickTechniqueCooldowns` for every unit once near the start of `advanceTick`, before actors choose actions. Keep normal attacks available when no technique is ready.

function combatTechniqueViewRows(unit, elapsedTicks) {
  const rows = (unit.techniques || []).slice(0, 3).map(function (technique, index) {
    return {
      slotIndex: index,
      techniqueId: technique.techniqueId,
      name: technique.name || technique.techniqueId,
      cooldownTicks: Math.max(0, Number(technique.cooldownTicks) || 0),
      remainingCooldownTicks: Math.max(
        0,
        Number(unit.cooldowns && unit.cooldowns[technique.techniqueId]) || 0
      ),
      triggered: unit.lastTechniqueId === technique.techniqueId &&
        unit.lastTechniqueTick === elapsedTicks - 1

  });
  if (rows.length === 0 && unit.sourceType === 'enemy') {

      cooldownTicks: unit.actionIntervalTicks,
      remainingCooldownTicks: unit.cooldownTicks,
      triggered: false
    });

}
