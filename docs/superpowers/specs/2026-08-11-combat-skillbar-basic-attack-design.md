# 战斗技能栏与具名普攻设计

日期：2026-08-11  
状态：按产品决策落地  
范围：取消释放条件；技能栏 4 格；具名普攻

## 1. 决策

1. **取消可配释放条件**：玩家只选择上阵功法；是否释放只看冷却与真气。
2. **技能栏 4 格**：第 1 格固定为具名普攻；后 3 格为可配置主动功法（仍按境界解锁 1→2→3）。
3. **不叫「普攻」**：我方按主武器形态具名；敌方按形象类型具名。

## 2. 释放规则

从左到右检查 **功法槽**（技能栏第 2–4 格）：冷却就绪且真气足够则释放第一本可用功法。  
若无可用功法，释放 **第 1 格具名普攻**（消耗行动间隔作为冷却，无真气消耗）。

## 3. 我方具名普攻（主武器）

按已装备武器显示名关键字归类（无武器时用「徒手」）：

| 形态 | 判定关键字 | 技能名 | 效果意图 |
|------|------------|--------|----------|
| 剑 | 剑 | 剑光斩 | 标准武器打击 |
| 刃 | 刃 | 裂刃斩 | 标准武器打击 |
| 枪 | 枪 | 穿云刺 | 标准武器打击 |
| 杖 | 杖 | 振法击 | 标准武器打击 |
| 徒手 | （无武器） | 碎空拳 | 徒手打击 |

数值仍用现有普攻公式（`attack × (1 + normalAttackBonus)`），本阶段只改名称与展示。

## 4. 敌方具名普攻（形象类型）

敌人增加 `form` 字段（与美术「类型」对齐）：

| form | 技能名 |
|------|--------|
| beast | 撕咬 |
| construct | 砸击 |
| insect | 螫刺 |
| plant | 缠绞 |
| mire | 淤击 |
| spirit | 魂噬 |
| remnant | 残袭 |
| avian | 俯冲 |
| default | 扑击 |

## 5. 非目标

- 恢复条件编辑器  
- 普攻按武器改伤害公式（可后续）  
- 把普攻做成可替换的功法书
