# 敌人形象美术规范 v3：正面中立姿态

日期：2026-07-31

## 1. 修订原因

v2 虽然把三个人形统一成了半身，但“左侧脸、双臂交叠”的动作过强，导致所有人形像同一角色换装，也不符合用户希望的自然展示方式。

另外：

- 地脉猿王的岩石结构、地脉纹和身体切面过多；
- 岩石傀儡仍像圆角机甲，不像本游戏里的轻仙侠石偶；
- 棘刺兔和噬魂蛾已经获得认可，不应因追求绝对朝向统一而重做。

v3 正式风格名为：

```text
enemy-v3-front-neutral-xianxia
```

中文名称为“无描边轻仙侠·正面中立敌人风”。

本规范继承 v2 的卡通比例、无描边与透明素材规则；发生冲突时以本文件为准。

## 2. 本轮范围

### 2.1 冻结并保留

以下两张 v2 素材不重新生成、不改变像素：

- `thornHare` 棘刺兔；
- `soulMoth` 噬魂蛾。

它们可以保留当前朝向，作为已经通过的例外。

### 2.2 重新生成

只重做以下五张：

- `stonePuppet` 岩石傀儡；
- `rogueCultivator` 邪修；
- `thunderJudge` 雷罚使；
- `earthVeinApe` 地脉猿王；
- `myriadLawAvatar` 万法化身。

## 3. 正面中立构图

### 3.1 人形敌人

`rogueCultivator`、`thunderJudge` 和 `myriadLawAvatar` 使用同一正面半身模板：

- 头部与身体完全正对玩家；
- 画面显示头部至腰部下缘；
- 脊柱垂直，肩线水平；
- 双臂从肩部自然向下；
- 双手停留在腰部两侧并完整可见；
- 手臂与身体之间保留小间隙，避免粘成一个色块；
- 左右手不交叉、不抱胸、不抬起、不做法术动作；
- 身体不扭转，不出现侧脸或三分之四视角；
- 腰部下缘使用自然衣摆或能量形态收口，不出现腿部。

三个人形的头顶、下巴、肩线、手肘、双手和腰部裁切位置必须对齐。

### 3.2 类人造物与兽类

`stonePuppet` 和 `earthVeinApe` 使用正面完整身体：

- 头部正对玩家；
- 躯干不扭转；
- 左右肩基本对称；
- 双臂自然下垂；
- 双手、拳头或前掌位于身体两侧；
- 不冲刺、不挥拳、不使用三分之四攻击姿态；
- 双脚或后肢稳定落在同一水平线附近。

## 4. 身份设计

### 4.1 邪修

- 正面半身，双臂垂下；
- 大头、短颈、简化面部；
- 深酒红短袍、炭紫内领、深紫束发；
- 不持护符、兵器或法宝；
- 通过发型、眉眼和袍服主色识别；
- 只使用 3–5 个主要造型块。

### 4.2 雷罚使

- 与邪修使用完全相同的正面半身姿态；
- 靛蓝和暗紫袍服；
- 一块连成整体的宽肩甲作为唯一精英结构；
- 取消短杖；
- 一条宽的浅青雷纹贴附在一侧垂下的衣袖上，不伸出主体；
- 不使用雷环、雷叉、散落电火花；
- 只使用 5–7 个主要造型块。

### 4.3 万法化身

- 与邪修使用完全相同的正面半身姿态；
- 单一正面面孔、深紫中央身体、暖象牙色内层；
- 胸口只保留一个青紫核心；
- 肩后只保留三片宽而圆的相连法相板；
- 法相板左右对称或近似对称；
- 双手垂下，不托举、不掐诀、不张开手掌；
- 只使用 5–7 个主要造型块。

### 4.4 岩石傀儡

岩石傀儡不再使用机器人或机甲结构。

- 正面完整身体，双臂垂下；
- 整体像由少量河滩圆石组成的矮胖石偶；
- 一个大圆角石头作为头部；
- 一个更大的圆角石头作为身体；
- 两条短粗石臂直接连接身体两侧；
- 两只宽石脚直接承托身体；
- 允许一个小型扁平赭黄胸核；
- 不使用肩甲、护腕、关节环、机械缝、金属结构或六边形装甲感；
- 不绘制石头裂纹、浮雕符文或写实材质；
- 主体只使用灰褐主色、一个暗面和赭黄胸核。

### 4.5 地脉猿王

- 正面完整身体，双臂自然下垂，拳头靠近身体两侧；
- 头部放大，脖颈缩短，身体宽而矮；
- 删除肩背岩脊和独立岩石板；
- 删除写实肌肉、毛发边缘与详细手指；
- 地脉纹只保留左右肩各一块宽赭黄色面；
- 胸口、手臂和腿部不再铺满地脉纹；
- 使用 5–7 个主要圆润造型块；
- 压迫感来自宽度和大拳头，不来自复杂纹理。

## 5. 卡通渲染

- 无黑色描边、无线稿。
- 大色块、圆润边缘、低细节。
- 每个主要部位只允许主色、一个亮面和一个暗面。
- 禁止连续渐变塑造写实体积。
- 禁止机甲装甲、复杂衣褶、写实面部结构、写实肌肉和写实毛发。
- 眼睛、鼻子、嘴和手指必须继续概括。
- 正面构图不能变成证件照：通过头身比例、颜色和身份结构保留敌意。

## 6. 输出方式

v2 保留不覆盖：

```text

```

v3 完整批次输出到：

```text

```

v3 目录仍包含七个敌人的完整集合：

- 棘刺兔和噬魂蛾从 v2 原样复制；
- 其余五张使用 v3 新生成素材。

每个敌人输出：

```text

```

总览文件：

```text

```

接触表每行显示：

- v3 的 256px 透明底预览；
- v3 的 104px 桌面战斗框；
- v3 的 84px 竖屏战斗框；
- v3 的浅粉战斗卡效果；
- “保留”或“重做”状态。

## 7. 验收标准

### 7.1 姿态

- 三个人形全部正脸；
- 三个人形双臂全部自然垂下；
- 三个人形没有抱胸、交臂、侧脸、抬手或扭腰；
- 三个人形头顶、下巴、肩线、手肘、双手和腰部下缘位置接近；
- 石偶和猿王正面站立，双臂或拳头位于身体两侧。

### 7.2 风格

- 岩石傀儡第一眼是圆润石偶，不是机器人、机甲或穿甲岩人；
- 地脉猿王比 v2 明显减少岩块、地脉纹、肌肉和毛发细节；
- 五张重做素材与已经通过的棘刺兔、噬魂蛾属于同一种卡通渲染；
- 84px 下仍能区分普通、精英和首领；
- 不依赖兵器、抱手姿态或复杂特效识别身份。

### 7.3 技术

- 512×512 PNG RGBA 透明母版；
- 256×256 PNG RGBA 预览；
- 四角透明；
- 主体占画布 80%–88%；
- 视觉中心偏差不超过画布 3%；
- 无绿色或品红色色键边缘；
- v3 中 `thornHare` 与 `soulMoth` 的对应文件必须与 v2 字节一致；
- 其余五张必须与 v2 不同。

## 8. 本轮边界

本轮只生成和评审 v3 七张完整样张集合。

本轮不：

- 修改敌人名称、数值、阶级或剧情；
- 覆盖 v1 或 v2 原型；
- 接入 `assets/enemy-portraits/`；
- 修改 `ui.js`、`styles.css` 或 `release/`；
- 在用户确认前把 v3 当作正式运行资源。
