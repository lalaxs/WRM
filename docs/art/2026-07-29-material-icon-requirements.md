# 材料与制造体系图标美术需求表

日期：2026-07-29

## 统一风格

- 风格：参考《银河奶牛放置》的简约扁平矢量绘制风格，透明背景，无文字。
- 尺寸：建议先产出 512x512 PNG，保留可回溯矢量源文件。
- 构图：主体居中，占画布 72% 到 82%，背包 48px 格内仍可辨认轮廓。
- 光影：低层级少高光，高层级可加入少量发光边缘，但不要复杂背景。
- 品质色：green、blue、purple、orange、red 只作为小面积点缀，不要覆盖物品本体识别色。
- 描边：当前已确定为无描边、低阴影、单主体，不使用厚边线或装饰背景。
- 数据源：`content/materials.js` 的 `MaterialContent.artRequirements()` 是后续批量生成和回填图标的主数据。
- 本版新增：Herblore 1:1 药剂映射，共 72 个药剂系列、288 个丹药道具，并补齐 91 个炼丹辅材映射。
