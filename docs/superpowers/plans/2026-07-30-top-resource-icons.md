# Top Resource Icons Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Generate and integrate five readable top-bar icons for 灵石、精气、心情、声望、寿元 while preserving the current portrait H5 shell and gameplay data flow.

**Architecture:** Generate each icon independently with the built-in image tool, remove a flat chroma-key background locally, and derive centered 100px and 50px RGBA PNGs under a dedicated resource-icon directory. The DOM top bar continues to read through `GameAPI.queries.top()`; `ui.js` replaces colored dots with image nodes and adds the already-exposed lifespan value, while `styles.css` keeps all five pills on one row at 390px.

**Tech Stack:** Native JavaScript, DOM/CSS, RGBA PNG assets, built-in ImageGen, local chroma-key removal helper, Node self-tests, TapTap H5 release/package scripts.

## Global Constraints

- Use the accepted `v4-no-outline` flat-vector style: single subject, no outline, no border, no text, no particles, low shadow, transparent background.
- Final assets are exactly 100×100 and 50×50 RGBA PNGs with transparent corners and centered visible bounds.
- Resource order is exactly `lingshi`, `jingqi`, `mood`, `shengwang`, `shouyuan`.
- Lifespan displays remaining years and uses `∞` when `info.shouyuan` is `null`.
- Do not change resource production/consumption, save schema, simulation, lifespan settlement, or add the future paired-cultivation feature.
- Edit root source only; `release/` is generated by `npm run sync-release`.
- Preserve all pre-existing uncommitted workspace changes. If a task file already contains user changes, do not create a commit that would include those changes.

- [ ] **Step 1: Write the failing asset test**

Create `selftest_top_resource_icons.js` with this contract:

```js
'use strict';

const assert = require('assert');
const fs = require('fs');
const path = require('path');
const {
  alphaBounds,
  readPngRgba
} = require('./scripts/png-rgba.js');

const ROOT = __dirname;
const IDS = ['lingshi', 'jingqi', 'mood', 'shengwang', 'shouyuan'];

function centeredOffset(image, bounds) {
  return {
    x: Math.abs((image.width - 1) / 2 - (bounds.minX + bounds.maxX) / 2),
    y: Math.abs((image.height - 1) / 2 - (bounds.minY + bounds.maxY) / 2)
  };
}

let checked = 0;
[100, 50].forEach(function (size) {
  IDS.forEach(function (id) {
    const relative = path.join(
      'assets',
      'resource-icons',
      String(size),
      id + '.png'
    );
    const absolute = path.join(ROOT, relative);
    assert(fs.existsSync(absolute), relative + ' must exist');
    const image = readPngRgba(absolute);
    assert.strictEqual(image.width, size, relative + ' width');
    assert.strictEqual(image.height, size, relative + ' height');
    const cornerIndexes = [
      3,
      (size - 1) * 4 + 3,
      ((size - 1) * size) * 4 + 3,
      (size * size - 1) * 4 + 3
    ];
    assert(
      cornerIndexes.every(function (index) {
        return image.data[index] <= 8;
      }),
      relative + ' must have transparent corners'
    );
    const bounds = alphaBounds(image, 8);
    assert(bounds, relative + ' must contain visible icon pixels');
    const offset = centeredOffset(image, bounds);
    const tolerance = size === 50 ? 1.5 : 2.5;
    assert(
      offset.x <= tolerance && offset.y <= tolerance,
      relative + ' must be centered; offset=' +
        offset.x.toFixed(2) + ',' + offset.y.toFixed(2)
    );
    checked++;
  });
});

assert.strictEqual(checked, 10, 'all resource icon sizes are checked');
console.log('Top resource icon self-test passed: ' + checked);
```

Add `'selftest_top_resource_icons.js'` to the ordered file list in `selftest_all.js`.
