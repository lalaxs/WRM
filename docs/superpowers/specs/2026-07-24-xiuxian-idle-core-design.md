# 修仙放置游戏唯一核心设计规格

**状态：** 已确认，作为玩法、代码、测试和文案的唯一执行依据。  
**日期：** 2026-07-24  
**适用范围：** 根目录源码、发布目录、测试、后续内容配置与 UI 优化。

## 1. 产品定位

这是一款竖屏、单机、持续运行的修仙放置游戏。

核心结构是：

> 选择挂机行动 → 获得技能经验、资源与修为 → 加工资源并配置能力 → 完成副本或任务门槛 → 概率突破境界 → 建立人物关系并培养后代 → 传代或轮回后继续发展。

修炼放置是硬主轴，人物世界是深度驱动层。人物关系会影响资源、技能、功法、事件和长期传承，但玩家始终可以不依赖恋爱关系完成主要修炼进度。

游戏没有最终通关。境界、世代、宗门和家族发展提供阶段目标，世界持续运行。

目标日常主动操作时长为 20～40 分钟，主要用于处理离线收益、事件、关系、装备、功法、生产和突破准备。

## 2. 不可变更的产品边界

- 不制作大地图、地图格子、自由移动或地图探索操作。
- 大世界只通过人物数据、抽象地区、宗门状态、事件与传闻表现。
- 保留现有“顶部状态 + 左侧页签 + 右侧内容区”整体 UI 框架。
- 不迁移到新的前端框架或游戏引擎。
- 继续使用原生 HTML、CSS、JavaScript、DOM UI 和现有角色 Canvas 合成方案。
- 游戏为纯单机世界，不提供玩家市场、玩家排行或共享世界。
- 网络只用于 TapTap 登录、云存档、广告及平台能力。
- 随机人物事件使用规则与人工模板生成，不在线调用生成式 AI。
- 根目录是唯一源码来源，`release/` 必须由源码同步生成，不能独立修改。
- 所有游戏文案使用“与某人一起修炼”“共同修炼”或“相伴修行”等审核安全表达。

## 3. 核心循环与行动槽

玩家只有一个主要挂机槽。

同一时间只能执行一种主要行动：

- 探索资源点与采集
- 炼丹、炼器、烹饪、制作符箓或阵法
- 普通战斗、副本、宗门任务或试炼
- 驯服和训练灵兽
- 陪伴、论道、出游、拜访、与某人一起修炼等主动社交

主要行动由玩家手动选择和切换：

- 不提供行动队列。
- 不根据目标自动替玩家选择下一行动。
- 行动自动重复，直到玩家停止、资源耗尽、条件失效、补给耗尽、战败或寿元进入安全缓冲。
- 所有有效行动都提供基础修为。
- 与修炼直接相关的行动可以提供更多修为。

灵田生长和事件产生的并行社交进度不占用主要挂机槽。

## 4. 技能体系

固定十二项生活技能：

1. 采药
2. 采矿
3. 伐木
4. 钓鱼
5. 炼丹
6. 炼器
7. 烹饪
8. 符箓
9. 魅力
10. 御兽
11. 种植
12. 阵法

通用规则：

- 十二项技能均为 1～99 级。
- 除魅力外，每个具体行动、配方、资源、鱼种、灵兽种类或阵法项目拥有独立熟练度。
- 技能等级负责解锁内容和提供整体能力。
- 熟练度负责提高具体行动的效率、额外产出、材料保留或成功表现。
- 所有新增技能和动作必须进入统一行动、在线推进和离线推进规则，不能各自实现第二套计时逻辑。

魅力例外：

- 魅力没有额外熟练度。
- 魅力通过社交行为自然增长。
- 魅力等级提高正面关系收益，降低普通误会概率，并解锁说服、调解和关系改变事件。
- 高魅力可以通过长期、可见的事件链改变 NPC 原本的感情原则，不能瞬间完成。

## 5. 采集、种植与生产

### 5.1 采药、采矿、伐木

- 玩家先挂机探索随机资源点。
- 资源点拥有随机种类、品质和有限容量。
- 发现后可持续采集，容量耗尽时行动停止。
- 不渲染地图，资源点只以 UI 卡片和事件文本展示。

### 5.2 钓鱼

- 玩家选择固定钓点。
- 每种鱼拥有可恢复库存。
- 库存随时间恢复。
- 同种鱼在不同钓点共享该鱼种的熟练度。

### 5.3 种植

- 灵田位于洞府。
- 多个地块可以分别播种和收获。
- 作物按完整现实时间生长，离线继续。
- 成熟作物不会腐烂。
- 种植不占用主要挂机槽。
- 收获时获得种植经验和作物熟练度。

### 5.4 生产

- 炼丹、炼器、烹饪、符箓和阵法制作消耗具体材料并占用主要挂机槽。
- 配方由技能等级、宗门、副本、人物指点和事件解锁。
- 生产结果进入背包。
- 不增加统一生产队列。

资源循环固定为：

> 采集原料 → 加工制造 → 获得装备与消耗品 → 挑战战斗和副本 → 获得稀有材料、功法与种子 → 解锁更高级行动。

## 6. 背包与物品

- 同种物品堆叠并占用一个物品槽。
- 不同物品分别占用槽位。
- 初始槽位有限。
- 通过游戏内商城、成就和任务扩充槽位。
- 提供材料、装备、消耗品、功法书、任务物品等分类与筛选。
- 已装入战斗方案或被任务锁定的物品不可误售。
- 背包为独立左侧页签，不属于洞府。

## 7. 洞府

洞府只管理五个模块：

1. 灵田
2. 阵法
3. 灵兽
4. 会客厅
5. 传承殿

洞府不管理背包、炼丹、炼器、烹饪或符箓页面。

洞府没有摆放、装修或地图操作。模块使用现有右侧内容区中的卡片、列表、状态角标和进度条展示。

### 7.1 阵法

- 阵法是长期配置型增益。
- 制作阵法占用主要挂机槽。
- 完成后的阵法装入有限槽位。
- 阵法持续生效，直到被替换、关闭或失去维持条件。
- 阵法可服务采集、生产、战斗、灵兽或人物互动。
- 阵法不直接提高突破概率。

### 7.2 灵兽

- 灵兽可在采集、探索、战斗和人物事件中遇到。
- 驯服与主动训练占用主要挂机槽。
- 每只灵兽拥有等级、种类熟练度、随机特性和成长倾向。
- 灵兽可以协助战斗，也可以提供采集、制造或社交增益。
- 玩家可拥有多只灵兽，但只能配置有限数量的当前协助灵兽。

### 7.3 会客厅

会客厅集中展示并行社交进度，例如：

- 正在互寄书信
- 正在准备赴约
- 正在等待论道之日
- 正在打听某人的消息
- 正在为对方寻找礼物

同一个 NPC 同时只能存在一条并行社交进度，不同 NPC 的进度可以同时进行。

### 7.4 传承殿

传承殿是洞府建筑模块，负责：

- 族谱
- 历代角色传记
- 前世记录
- 传代与轮回方案
- 可继承技能熟练度选择
- 可继承功法、装备、资源、灵兽、阵法图纸和家族加成

传承殿等级决定完整继承槽位与可保存内容。升级需要境界、建筑材料和资源。

## 8. 战斗与副本

战斗占用主要挂机槽，采用自动结算。

玩家负责战前配置，不进行实时点击释放：

- 境界与基础属性
- 武器、防具和饰品
- 主动功法与被动心法
- 技能优先级和触发条件
- 丹药、食物、符箓与阵法
- 出战灵兽

战斗页面包含：

- 普通战斗区域
- 副本
- 宗门试炼
- 特殊秘境

普通区域：

- 选择敌人后持续自动战斗。
- 获得修为、材料、装备和功法残页。
- 直到玩家停止、补给耗尽或战败。

副本：

- 依次挑战固定普通敌人、精英和最终首领。
- 可包含多阶段首领、环境效果和敌人被动。
- 可以设置境界、前置副本和关键物品要求。
- 首次通关解锁系统、功法、装备或突破条件。
- 重复通关提供持续掉落。
- 首次通关后可重复挂机挑战。

战败：

- 生命归零时重伤撤退。
- 普通战斗和副本不会造成永久死亡。
- 已使用的补给和时间不返还。
- 获得限时重伤状态。
- 只有明确标注的生死事件才可能造成永久死亡。

## 9. 功法技能

功法独立于十二项生活技能。

- 首次使用功法书后永久学会对应技能。
- 再次获得同名功法书时转化为升级经验。
- 实战、NPC 指点和宗门修炼也可以提供功法经验。
- 主动功法装入有限主动槽。
- 被动心法装入独立心法槽。
- 玩家可以保存多套战斗配置。

自动释放规则：

1. 从左到右检查主动技能。
2. 同时满足条件时优先使用更靠左的技能。
3. 可配置自身生命、灵力、敌人状态、自身增益和冷却等触发条件。
4. 没有技能满足条件时执行普通攻击。

宗门功法：

- 本门功法更早获得、要求更低、升级成本更少。
- 本门功法存在专属组合。
- 外门功法可通过人物指点、副本、奇遇和残页获得。
- 离开或更换宗门不会删除已学功法。

## 10. 境界、突破与寿元

### 10.1 突破任务

每个境界拥有明确前置条件，例如：

- 通关指定副本
- 击败指定首领
- 完成宗门试炼
- 完成关键任务
- 获得特殊物品

前置条件一旦完成便永久记录，突破失败不要求重做。

### 10.2 突破概率

突破成功率只允许三个来源：

> 境界基础成功率 + 丹药加成 + 事件增益

- 功法、装备、符箓、阵法、灵兽、关系和洞府不得直接修改突破概率。
- 最终概率可以达到 100%。
- 玩家可以提前冒险，也可以准备到必定成功。
- 突破成功进入下一境界并增加寿元。
- 突破失败清空当前境界修为并消耗本次丹药。
- 突破失败保留前置任务记录。

### 10.3 寿元

- 境界越高，基础寿元越长。
- 突破、丹药、奇遇和特殊功法可以延长寿元。
- 玩家离线时不会无提示地直接寿尽。
- 玩家寿元接近终点时，主要挂机行动停止并保留少量缓冲。
- 寿元进入安全缓冲的瞬间弹出**一次性**「寿元将尽」提示弹窗，提醒玩家完成传承或转生；不自动替玩家转生。
- NPC 不享受玩家的停止保护。
- 修仙人物死亡不作为高频日常事件。

## 11. 宗门与抽象地区

玩家开局为散修，完成基础教学后通过正式事件选择宗门。

宗门：

- 固定设计宗门身份与特色。
- 正式内容目标为 4～6 个宗门。
- 大部分成员随机生成。
- 宗门影响生活技能效率、功法流派、资源、任务、试炼、NPC 倾向和事件权重。
- 本门内容更早、更容易获得，但不永久封锁其他宗门内容。
- 玩家可通过事件退出或更换宗门。
- 退出影响贡献、声望和人物关系，不删除已学能力。

宗门自身持续变化：

- 掌门和职位更替
- 成员加入、退出与死亡
- 宗门强弱和声望
- 联盟、竞争和敌对关系

宗门不会永久消失，避免核心内容断档。

世界保留城镇、坊市、宗门驻地、山林和秘境等抽象地区。地区只作为人物状态、资源来源和事件条件存在，不提供地图。

## 12. NPC 世界

所有 NPC 随机生成并永久保存。

NPC 基础字段至少包括：

- 身份、姓名、外貌、性别和年龄
- 境界、修为、寿元和天赋
- 性格、价值倾向和感情观
- 地区、宗门与家族
- 技能、功法、物品与经历
- 关系、传记与重要事件

NPC 会在玩家在线和离线时自主：

- 修炼和突破
- 加入或离开宗门
- 迁居和游历
- 结交和结仇
- 恋爱、成为伴侣和分手
- 生育与培养后代
- 衰老、死亡、转世和飞升

玩家可以影响 NPC，但不能直接控制 NPC 的人生选择。NPC 最终依据性格、关系、利益和环境作出决定。

时间节奏：

- 普通人物一代约持续现实中的 4～8 周。
- 高境界人物寿命显著更长。
- 世界在玩家离线时继续运行。

性能分层：

- 活跃人物圈约 30～50 人，进行高频详细模拟。
- 背景人物池进行低频简化模拟。
- 背景人物与玩家产生联系后进入活跃圈。
- 人物离开活跃圈时不会被删除。

## 13. 关系、恋爱与魅力

玩家角色固定为女性。所有性别的 NPC 都可以成为好友、恋爱对象或正式伴侣。

任意两个人物之间记录八项有方向的关系值：

1. 好感
2. 信任
3. 恋慕
4. 欲望
5. 依赖
6. 忠诚
7. 嫉妒
8. 怨恨

A 对 B 与 B 对 A 分开记录。玩家可以查看这些数值，NPC 与 NPC 使用相同规则。

关系阶段不会只因数值达标自动变化。数值只负责解锁事件，好友、恋人、正式伴侣、疏远、分手和决裂由事件中的双方决定。

NPC 感情原则可随机为：

- 接受开放关系
- 可以协商
- 倾向专一
- 强烈要求绝对专一

玩家可以通过长期事件和魅力影响这些原则，但不能瞬间改变。

通用互动：

- 交谈
- 赠礼
- 陪伴
- 论道
- 出游
- 拜访
- 与某人一起修炼

NPC 根据身份、性格、技能与宗门拥有专属互动。

玩家主动发起的社交占用主要挂机槽，并根据互动与人物身份提供修为、技能经验、资源、功法理解或临时增益。

感情冲突采用“可管理”原则：

- 允许嫉妒、竞争、争吵、疏远、分手和结仇。
- 风险通过数值、人物态度和事件提示提前表现。
- 玩家拥有解释、补偿、协商和退出机会。
- 不允许无预警销毁存档、夺走全部资源或强制控制角色。

不可恋爱范围：

- 血亲
- 直系姻亲
- 监护关系
- 前代正式伴侣

## 14. 事件系统

事件使用：

> 确定性规则判断 + 人工事件模板 + 人物变量填充

每个模板包含：

- 触发条件
- 参与人物
- 性格与关系要求
- 地区、宗门或境界条件
- 展示文本
- 玩家选项
- 即时结果
- 延迟结果
- 后续事件
- 冷却时间

每天目标产生约 5～10 个需要玩家处理的关键事件。其他人物行为压缩为摘要。

待处理事件：

- 不会过期。
- 不会被新事件覆盖。
- 建议容量约 20 条。
- 达到容量后暂停产生新的玩家参与型关键事件。
- NPC 自主事件仍继续运行并进入世界摘要。

玩家回复事件后，可产生不占主挂机槽的并行社交进度。进度必须使用具体行为名称，不能显示生硬的系统等待词。

## 15. 事件页与离线收益页

玩家上线时先进入离线收益结算详情页，确认后进入正常游戏。

离线收益详情显示：

- 实际离线时间与有效结算时间
- 离线行动
- 完成次数和停止原因
- 获得物品
- 技能经验、熟练度和修为
- 消耗的材料与补给
- 等级提升和新解锁
- 灵田及并行社交完成数量
- 新增待决策事件与世界事件数量

离线收益页不逐条展开人物和世界事件。

同一份离线结算记录归档到“事件”页。

事件页包含：

1. **事件摘要**
   - 离线结算
   - 行动停止原因
   - 灵田与并行进度完成结果
   - 重要人物和宗门变化汇总
2. **待决策事件**
   - 需要玩家选择、参与或回复的事件
   - 已完成并行进度后的后续事件
3. **世界演变**
   - NPC 修炼、关系、生育、死亡、转世和飞升
   - 宗门与家族变化
   - 可按身边动态和天下传闻筛选

## 16. 离线规则

主要挂机行动离线结算上限：

- 初始 12 小时
- 通过境界里程碑、成就和游戏内商城提升到 24 小时
- 中后期提升到 36～48 小时

不受主要挂机上限限制：

- 灵田完整现实时间生长
- 并行社交进度
- NPC 世界
- 年龄与寿元

行动中断：

- 资源点耗尽立即停止。
- 制作材料耗尽立即停止。
- 战败、补给耗尽或重伤立即停止。
- 玩家寿元进入缓冲立即停止，并向玩家弹出一次性缓冲提示。
- 剩余离线时间不自动用于其他行动。

在线与离线必须调用同一套模拟规则。

## 17. 后代、传代、轮回、转世与飞升

任意性别的正式伴侣可通过修仙世界观中的传承仪式共同孕育后代。

后代继承：

- 部分外貌
- 天赋倾向
- 性格倾向
- 宗门与家族背景
- 少量特殊能力或血脉

玩家可以拥有多名后代。成年后代成为正常世界人物。玩家选择一名作为继承人，其他后代继续作为永久 NPC。

进入寿元安全缓冲不会自动转生；玩家需手动在传承殿发起人生转换，或点击缓冲提示弹窗的「开始人生转换」。

玩家当前角色寿元结束、主动传代或飞升时可以：

1. 选择成年后代继承。
2. 创建全新身份进入新轮回。

两条路线都通过传承殿保留主要养成成果：

- 十二技能等级不重置。
- 传承殿决定可完整继承的具体熟练度数量。
- 未选熟练度保留一部分。
- 可继承功法、部分装备与资源、灵兽、阵法图纸、家族加成和宗门关系。

新轮回角色拥有新身份、外貌、出身和天赋组合。旧社会关系全部重新开始，只能通过信物、记忆觉醒和特殊事件重新相认。

前代玩家角色进入族谱、传记和传承殿记录，不作为普通活跃 NPC 继续参与日常关系。

NPC 转世：

- 生成全新身份。
- 只继承少量隐藏天赋、性格倾向和前世印记。
- 不自动恢复原有关系。

NPC 飞升：

- 离开日常人物池。
- 保留完整传记。
- 可通过梦境、赐福、信物或特殊事件影响下界。

## 18. 页面结构

整体骨架固定：

- 顶部状态区
- 左侧可滚动页签
- 右侧独立滚动内容区
- 全屏弹层

主要左侧页签：

- 洞府
- 背包
- 商城
- 事件
- 探索
- 战斗
- 功法
- 宗门
- 天下
- 关系
- 设置

独立技能页：

- 采药
- 采矿
- 伐木
- 钓鱼
- 炼丹
- 炼器
- 烹饪
- 符箓

洞府内技能：

- 种植
- 阵法
- 御兽

关系页展示：

- 魅力

“天下”替换原“排行”，只展示本地 NPC、宗门、家族、境界人物和重大变化。

“探索”不提供地图，只提供游历、奇遇、调查和特殊地点事件。

“战斗”页面内部切换普通区域、副本、宗门试炼和特殊秘境。

现有 UI 的总体布局、交互方向和样式基调保持不变，只优化信息层级、数值说明、状态反馈和关键数据可读性。

## 19. 存档、随机与模拟架构

存档必须具备：

- 单一版本化快照
- `schemaVersion`
- 旧 `cloud_*` 多键存档迁移
- JSON 往返一致性
- 写入前备份
- 读取校验与损坏恢复
- 离线结算幂等
- 本地与 TapTap 云存档冲突时由玩家选择

可持久化状态只包含游戏世界和玩家进度，不保存 DOM、Canvas、导航缓存、弹窗对象或运行计时器。

永久重复行动不得使用 JSON 无法表示的数值，必须使用明确的可序列化标记。

随机数必须可注入、可复现并保存必要状态。掉落、探索、事件、突破和人物生成不得直接散落调用全局随机数。

模拟必须是纯逻辑：

- 不访问 DOM。
- 不访问 Canvas。
- 不直接弹提示。
- 不直接写存档。
- 在线与离线调用相同的 `advance` 规则。

UI 只通过查询接口读取 ViewModel，通过命令接口修改游戏，不直接改内部可变状态。

## 20. 分阶段完成标准

不以“是否好玩”作为阶段继续条件。所有已确认系统必须完成。

每个阶段只有工程验收门槛：

- 该阶段规格全部实现。
- 新功能先有失败测试，再实现通过。
- 旧测试与新增测试全部通过。
- 存档迁移与 JSON 往返通过。
- 在线与离线结果一致。
- UI 骨架没有回归。
- 独立审查不存在未修复的严重或重要问题。
- `release/` 与源码同步。

阶段顺序：

1. 基础架构、存档迁移、统一时间与行动模拟
2. 十二技能、资源网络、背包与洞府模块
3. 自动战斗、副本、功法与突破
4. NPC、关系、魅力、事件、宗门与天下
5. 寿元、后代、传承殿、轮回、转世、飞升与长期世界
6. 全量内容整合、UI 信息优化、性能、回归与发布

主 Agent 在每阶段完成后独立审查并自动推进下一阶段。只有规格发生真实冲突、需要新外部权限或出现无法安全推断的产品选择时才暂停。
