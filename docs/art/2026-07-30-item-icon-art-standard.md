# 道具图标美术规范

日期：2026-07-30

## 当前结论

之前已经生成过一批道具美术图，当前正式采用的风格名为 `v4-no-outline`，也就是“无描边简约扁平矢量风格”。

这套风格来自多轮确认后的结果：最初参考《银河奶牛放置》这类小尺寸放置手游图标的清晰度和扁平质感，随后明确收敛为“矢量扁平、主体简约、不要杂乱装饰、少阴影、不要描边线、透明底”。注意这里不是复刻对方具体图形资产，而是借鉴小尺寸图标的可读性方向，再替换成我们修仙题材的材料、丹药、符咒、矿石、战斗掉落等主体。

## 核心风格

- 画风：简约扁平矢量感。
- 主体：单一具象主体，只画物品本身。
- 构图：主体居中，占画布约 72% 到 84%，四周留均匀透明边距。
- 背景：最终入库资产必须是透明背景，不允许白底、色块底、相框底。
- 描边：不允许描边，不是“细描边”，而是无描边、无外轮廓线、无黑线稿。
- 阴影：尽量不用阴影；如必须使用，只能是很轻的柔和体积阴影，不能有投影背景。
- 装饰：不允许装饰粒子、光圈、徽章、边框、角标、文字、水印。
- 识别：50px 背包格内必须能看清轮廓，14px 顶部资源图标也要能通过主色和形状区分。

## 禁止项

- 不使用 emoji 作为正式图标。
- 不使用厚边线、黑边、描边、卡通线稿。
- 不使用复杂背景、渐变光圈、装饰碎片、符号雨。
- 不使用文字、汉字、英文、数字标识。
- 不使用多个主体拼盘，除非物品定义本身就是“材料包”或“组合件”。
- 不交付带白色不透明底的 PNG。
- 不让主体偏离画布中心。

## 标准提示词

代码中 `content/materials.js` 当前沉淀的基础提示词结构是：

```text
简约扁平矢量，透明背景，无文字，手游背包格可读，{道具名}，{视觉族}，{美术细节}
```

后续用图像生成工具批量生产时，建议使用更完整的正式模板：

```text
用途：小尺寸手游道具图标。
画风：简约、干净、扁平矢量插画，匹配当前 v4-no-outline 道具图标规范。
画布：正方形图标，最终交付透明背景 PNG。
构图：一个居中的道具主体，清晰剪影，主体占画布 72% 到 84%，四周留均匀边距。
渲染：纯净色块，少量克制高光，极低阴影或无阴影。
限制：无描边、无线稿、无边框、无徽章、无装饰粒子、无文字、无水印、无背景图案。
主体：{道具名}，{视觉族}，{美术细节}。
小尺寸要求：在 50px 背包格内仍可读，轮廓和主色必须明确。
```

如果生成工具必须先给纯色底或白底，那个只允许作为中间素材。正式入库前必须抠成 RGBA 透明底，并重新居中裁切。

## 负向提示词

```text
不要描边，不要黑色轮廓，不要线稿，不要厚边线，不要白色背景，不要相框，不要圆形徽章，不要装饰粒子，不要复杂光效，不要文字，不要水印，不要多个物品堆叠，不要写实摄影，不要 3D 渲染。
```

## 资产规格

正式入库资产分两档：

| 规格 | 用途 | 要求 |
| --- | --- | --- |
| 100x100 PNG | 标准道具源图 | RGBA、透明背景、主体居中 |
| 50x50 PNG | 背包、掉落列表、小图标 | RGBA、透明背景、由 100px 高质量缩放 |

少量形状极简单且需要程序化统一的矿石、宝石、灵石资源，可以使用 SVG；但 SVG 也必须遵守同一套视觉原则：无描边、无背景、单主体、居中、扁平。

当前正式图标目录：

```text
assets/item-icons/100/
assets/item-icons/50/
assets/resource-icons/100/
assets/resource-icons/50/
```

## 视觉族规则

每个材料道具在数据表中应尽量带有 `visualFamily` 和 `artDetail`，用来保证同类物品批量生成时稳定。

| 类别 | 视觉方向 |
| --- | --- |
| 矿石 | 单块矿石或晶矿，硬质切面，按品阶提升颜色和稀有感 |
| 金属锭 | 单块锭形，简洁倒角，突出材质色 |
| 宝石 | 单颗切面宝石，形状明确，避免复杂光效 |
| 草药 | 单株或单束药草，叶形清晰，颜色区分品阶 |
| 种子 | 单粒或少量种子，避免画成一堆杂点 |
| 战斗材料 | 牙、骨、鳞、血、核等单主体掉落物，轮廓强，避免血腥写实 |
| 符咒材料 | 符纸、符纹包、灵髓等，以单个符件或能量物承载，不写文字 |
| 丹药 | 单枚丹丸或小瓶丹药，按效果类型用颜色区分，不使用文字标签 |
| 装备胚 | 单件武器胚、护甲片、盾核、冠履等，保持装备部位可辨识 |
| 饰品 | 单枚戒指或吊坠，宝石与金属比例清楚 |

## 质量检查

入库前必须检查：

- 四角 alpha 为透明，不存在白底。
- 主体视觉中心接近画布中心。
- 100px 和 50px 均存在，文件名和 `itemId` 一致。
- 50px 下能看清是什么，不靠文字解释。
- 没有描边、线稿、背景框、粒子、文字、水印。
- 背包、战利品列表、tips 中调用的是同一个图标映射。
