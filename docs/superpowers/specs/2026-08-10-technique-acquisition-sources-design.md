日期：2026-08-10

## 1. MWI 能力怎么来、怎么养成（事实）

来源：[Abilities](https://milkywayidle.wiki.gg/wiki/Abilities)、新手指南

| MWI 机制 | 含义 |
|----------|------|
| Ability Book | 消耗后永久学会对应 Ability |
| 战斗区怪物掉落 | **主通道**：挂机刷区就能掉书；某区绑定若干本，单本约 **0.5%～1%** |
| 地下城宝箱 | **集中通道**：通关开箱，相关书可到 **约 50%** |
| 重复书 | **养成主粮**：给该 Ability **大量 XP**（T1=50，T2+=500） |
| 实战使用 | 每次释放 **0.1 XP**（可忽略，只是微量滴漏） |
| 升级收益 | 等级提高 Ability 效果强度 |
| Marketplace | 可买书（本游暂无，不照搬） |
| 分阶 | 约 56 本，按等级需求分 5 档 |
| 养成节奏（指南） | 前期靠书冲到可用档；中期继续吃书；终局一直吃重复书 |

要点：

1. **区域挂机会掉能力书**；稀缺感来自「区绑书 + 单本百分点级」。
2. **变强几乎全靠重复书**；挂机释放不是正经升级手段。
3. 地下城是冲指定书 / 囤重复书的加速点。

## 3. 三层获取（玩家体感）

### 层 A · 区域挂机（MWI Zone）

- `normal:N`：**掉本阶功法书池**
- 概率：**1.2%** 抽中池内一本（均匀）  
  - 约等于「池内每本 ≈ 1.2%/池大小」；T1 池 7 → 单本约 0.17%；T3 池 28 → 单本约 0.04%  
  - 体感：挂区会慢慢出书、囤重复书，但不会像以前 2% 任意书那样刷爆
- 材料/补给仍为主产（与 MWI 精华、材料并列）

### 层 B · 秘境精英 / Boss（MWI 精英怪 + 箱的浓缩）

- 精英：**4%** 本阶书池  
- Boss：**8%** 本阶书池  
- 明显高于区域，鼓励刷秘境冲书与重复书

### 层 C · 首通里程碑

- 九秘境各绑 **唯一** 固定书（开荒锚点）
- 名单：碎石拳、流火掌、惊雷印、万剑凌霄、玄龟镇岳诀、御灵真诀、高山流水、众生倾意、绝处逢生诀

### 辅线

- 论道 `techniqueUnderstanding` → 功法 XP（不发书；强度远低于刷书）

## 4. 养成（MWI Ability Leveling）

### 4.1 两轨经验，主次分明

| 来源 | 数值 | 定位 |
|------|------|------|
| 重复功法书（T1） | **50 XP** | 低阶书，对标 MWI Lv1 书 |
| 重复功法书（T2+） | **500 XP** | 养成主粮，对标 MWI Lv20+ 书 |
| 主动成功释放 | **1 XP** | 微量滴漏，对标 0.1/次 |
| 被动参战击杀 | **1 XP** | 微量滴漏（本游被动无「释放」） |
| NPC 论道 | 少量 XP | 辅线，不替代刷书 |

**禁止**把实战做成正经冲级手段：中后期一级需要数千～上万 XP，一次释放/击杀只有 1。

### 4.2 等级与曲线

- 上限 **Lv200**（与 MWI Ability / 技能上限一致）
- `xpNeed` 使用 **MWI 官方经验差分表**（累计至 Lv200 = 100,000,000,000）
  - L1→2 需 **33**；L39→40 需 **3301**；L199→200 需 **7,874,807,178**
  - 门派契合：`xpCostMultiplier = 0.9`
- 体感锚点（T2+ 书 @500，对标 MWI 指南）：
  - 约 **68 本** → Lv40（前期可用档）
  - 约 **506 本** → Lv60（中期）
  - 终局继续吃书冲向 Lv100～200

### 4.3 升级收益

- 旧 Lv20 强度预算（主动约 +38% / 被动约 +28.5%）映射到 **MWI Lv100**
- 公式：`1 + bonusAt100 × (level - 1) / 99`（主动 bonus=0.38，被动=0.285）
- Lv200 继续同速率成长（终局重复书仍有收益）
- 概率、段数、持续时间、真气、冷却等结构字段默认不随级成长（与主设计 3.5 一致）

### 4.4 玩家行为预期（对标 MWI 指南）

1. **开荒**：首通/区掉学会关键主动与被动，装进槽位就能打。  
2. **前期**：刷重复书把主力推到约 **Lv40**。  
3. **中期**：秘境冲高阶书与重复书，主力约 **Lv60**。  
4. **终局**：T6+ 全池继续掉重复书，无限喂向 Lv100～200。

## 6. 与错误对标的切割

| 曾误用的 IdleOn 思路 | MWI 正确思路 |
|---------------------|--------------|
| 普图几乎不掉能力书 | 普图（区域）**会掉**能力书 |
| 书≈星天赋极稀 | 书≈区绑 Ability，百分点级 |
| 地下城才是主粮 | 区挂机是主粮之一，本是加速与定点 |
| 实战刷熟练是正经成长 | **重复书才是正经成长**；实战只是滴漏 |
