# 敌人形象 v4：梅尔沃式近景构图设计

## 目标

在不重新生成角色、不改变 v3 造型与配色的前提下，将全部 7 个敌人调整为更大的近景头像构图。参考《Melvor Idle》战斗界面中“敌人是面板主要视觉焦点”的做法，只借鉴角色占比、裁切方式和小尺寸可读性，不复刻其具体角色设计。

本轮解决两个问题：

- 当前 v3 角色在方形头像框内仍然偏小；
- 完整全身构图让脚部占据过多面积，脸部和核心身份特征在 84px 下不够突出。

## 范围

全部 7 个敌人统一调整：

- `thornHare`（棘刺兔）
- `stonePuppet`（岩石傀儡）
- `soulMoth`（噬魂蛾）
- `rogueCultivator`（邪修）
- `thunderJudge`（雷罚使）
- `earthVeinApe`（地脉猿王）
- `myriadLawAvatar`（万法化身）

v3 的角色外观是唯一源素材。不得重新生图，不得重绘五官、服装、颜色或姿势。

## 构图原则

### 1. 近景化

以 v3 可见轮廓为基准，感知尺寸平均放大约 22%。由于每个敌人的宽高比不同，实际缩放允许在 `1.18×–1.35×` 之间调整，以满足统一的视觉裁切目标。

不能机械地给所有角色使用同一倍率；统一的是最终阅读感，而不是原始像素倍率。

### 2. 顶部锚定

角色不再按可见轮廓上下居中，而是按顶部安全区放置：

- 512px 母版的头顶或最高轮廓距离顶边 `16–24px`；
- 水平方向保持居中；
- 上半身身份特征位于画面中央区域；
- 超出画布的部分只允许从底部和少量左右边缘裁切。

### 3. 可控裁切

底部裁切是本轮的设计目标，不视为错误：

- 人形：裁至上腰附近，允许袍摆、袖口或手部下缘被裁；
- 岩石傀儡：允许裁掉脚部下缘；
- 地脉猿王：允许裁掉小腿和脚部，保留头、肩纹、胸口和垂臂轮廓；
- 棘刺兔：允许裁掉脚掌下缘，必须保留眼睛、双耳与背部棘刺识别点；
- 噬魂蛾：允许裁掉尾端，必须保留头部、双翼主体与胸口法核。

目标底部裁切量为原可见轮廓高度的 `8%–15%`。宽体角色允许左右各裁切不超过原可见轮廓宽度的 `4%`，但不能切掉关键识别特征。

噬魂蛾是唯一例外：它的主体是横向双翼，若强制满足上述底部裁切量，会同时裁掉过多翼尖。噬魂蛾以双翼贴近左右边缘、头部与胸核明显放大为验收目标，尾端裁切量不设下限。

### 4. 小尺寸优先

最终构图必须优先满足 84px 战斗头像：

- 眼睛或面部区域一眼可见；
- 胸口核心、肩部地脉纹、雷电袖纹等身份点不能被裁掉；
- 角色不能在头像框内显得有大面积空白；
- 不依赖脚部才能辨认角色。

## 分类构图

### 人形敌人

`rogueCultivator`、`thunderJudge`、`myriadLawAvatar`：

- 共用同一头顶安全线和脸部高度；
- 放大后裁到上腰；
- 继续保持严格正面与双臂自然下垂；
- 手部可以靠近底边，允许下缘轻微裁切；
- 三张图的头顶、眼线、肩线和胸口高度必须视觉对齐。

### 直立非人形

`stonePuppet`、`earthVeinApe`：

- 头、脸、胸口必须完整；
- 以肩部和胸口作为画面视觉中心；
- 只裁脚部和小腿，不裁双臂的主要轮廓；
- 猿王的肩部赭黄纹必须完整保留。

### 横向动物

`thornHare`、`soulMoth`：

- 允许使用比人形更高的缩放倍率；
- 可以轻微裁切左右边缘，以换取更大的面部和躯干；
- 棘刺兔保留双耳、眼睛、背刺；
- 噬魂蛾保留双翼主体、头部触角和胸核；
- 下方脚掌或尾端优先被裁。

## 技术规则

- 仅对 v3 透明母版做裁切、缩放和重新定位；
- 统一使用高质量 Lanczos 缩放；
- 不经过生成模型，避免外观漂移；
- 输出四角必须完全透明；
- 不允许新增绿色或品红抠图残边；
- 不修改游戏运行时代码，不替换正式资源。

- 关键身份特征全部保留；
- 84px 下脸部与主轮廓清晰；
