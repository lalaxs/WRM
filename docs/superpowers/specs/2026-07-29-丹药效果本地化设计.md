# 丹药效果本地化设计

日期：2026-07-29

目标：保留现有七十二个丹药系列、四阶结构、配方和美术需求，但把效果重写为本游戏自己的修仙放置系统。

## 设计原则

- 丹药服务单主行动槽、战斗方案、突破、寿元、灵兽、符修、社交和传承，不引入不属于本游戏的外部玩法名词。
- 背包数量表示拥有多少瓶；可用次数表示服用后还能触发多少次效果。
- 第一批优先接入已有系统：采集、生产、战斗基础属性、战斗补给、突破、钓鱼、灵田和战利品。
- 第二批接入需要扩展的系统：战斗状态、符修流派、灵兽协战、秘境环境、高阶炼丹和御兽消耗。
- 第三批作为玩法预留：游历探宝、观星悟道、秘境陷阱等事件型内容。

## 后续开发建议

1. 先做丹药状态框架：记录当前生效丹药、剩余可用次数、适用场景和冲突规则。
2. 第一批先接采集、生产和战斗基础属性，保证玩家马上能感知丹药价值。
3. 第二批再扩展战斗状态池，统一处理中毒、燃烧、流血、撕裂、沉默、恐惧、枯萎、虚爆等效果。
4. 符修丹药要和符咒消耗一起做，避免出现只加数值但没有资源压力的流派。
5. 灵兽丹药要等灵兽协战触发点稳定后再做，否则容易变成普通战斗增伤丹。
6. 第三批先保留在表内，不进入制作优先级，避免为了少数丹药提前开发整套游历或观星系统。
