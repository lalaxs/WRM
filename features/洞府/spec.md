# 功能规格：洞府（主页 / Homestead）

> **本文件是该功能的唯一权威规格**，内容以用户在对话中的描述为准。
> 任何改动由 `feature-module-dev` Skill 驱动：更新本文件并**彻底删除旧版本描述**，不在文档或游戏内保留冗余旧版（详见 Skill 第二节清理 SOP）。

## 功能定位
玩家个人洞府主页，游戏默认落地页（导航首项「洞府」）。整合玩家的私人养成子系统。

## 子系统（5 张卡片）
进入洞府先展示 **5 张卡片**，对应 5 个子系统；点卡片进入该子系统子页，子页内提供「← 返回洞府」按钮回到卡片页。
- 灵田（farm）：种植灵植，产出丹材 / 食材。
- 阵法（formations）：布置阵法，提供增益（如采集/钓鱼额外产出）。
- 灵兽（beasts）：栖息与养成灵兽。
- 会客厅（meetingHall）：人物与事件阶段开放（当前占位）。
- 传承殿（inheritance）：传承/轮回相关（当前占位）。

> 交互规则（用户 2026-07-28 明确）：灵田/阵法/灵兽等**不使用页签切换**，改用「卡片 → 子页」两级结构。旧页签式（subtabs）已从 `ui.js`/`styles.css` 整体清理。

## 洞府页显示规则
- **不显示当前境界**（筑基期/炼气期等）— 旧「境界卡」已删除。
- **不显示当前行动状态** — 旧「当前行动卡」已删除。
- 洞府页只承载：5 张卡片入口 + 各子系统子页内容。

## 当前行动状态（全局，统一位置）
- 显示位置：**顶部资源栏（顶栏）下方的拓展一栏**（`.action-bar`，全游戏常驻）。
- 空闲时：显示「空闲」，无进度条填充。
- 非空闲时：显示**对应行动的名字 + 行动进度条**（进度取自 `queries.home().current.progress`）。

## 离线判定（参考《梅尔沃放置》）
- 规则（用户 2026-07-28 明确）：**最小化网页 / App 切后台再回来，不判为离线**；仅**重新加载页面**（真正离开后回来）时，按存档 `processedThroughMs` 时间戳结算离线收益。
- 实现：`game.js` `handleVisibilityChange` 在「由后台回到前台」时仅恢复运行（清 `_hiddenAt`、对齐 `_last`），**不结算离线**；离线模拟只在加载路径（基于持久化时间戳）触发。手机端同理：后台保活 = 暂停，进程被杀后重进 = 离线结算。
