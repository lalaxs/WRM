# 材料模块细化设计

日期：2026-07-29

## 目标

本轮先把材料模块从“能用”整理到“可设计、可生成图标、可继续扩展”的状态。重点不是马上改运行逻辑，而是先形成一张稳定的材料画像表：每个材料都要知道它是什么、从哪里来、用在哪里、是否进背包，以及图标应该怎么画。

## 当前结论

当前 `content/items.js` 中共有 71 个 `material` 类物品。材料来源覆盖采矿、伐木、采药、钓鱼、灵田、生产和战斗，但结构还不完整。

主要问题：

1. `material` 分类过粗，缺少矿石、宝石、木材、灵草、水产、种子、战斗材料、系统包等二级分类。
2. 战斗掉落没有独立材料体系，目前只是按 1-9 阶复用矿石/晶石。
3. 多个材料有来源但没有用途，后续容易变成背包垃圾。
4. `灵石`、散装资源包、鱼宝箱这类系统物品和普通材料混在一起。
5. `雷灵草`、`血灵草`存在同名不同 ID，影响背包识别、tooltip 和图标生成。
6. 材料描述缺少来源/用途索引，tooltip 只能显示通用描述。
7. 当前图标主要是 emoji，不足以支撑正式美术资源。

## 建议材料字段

后续可以在物品配置或独立材料配置中补充这些字段：

| 字段 | 用途 |
| --- | --- |
| `materialType` | 二级类型，如 `ore`、`gem`、`wood`、`herb`、`fish`、`seed`、`battle_drop`、`currency`、`bundle` |
| `sourceTags` | 来源系统，如 `gathering:mining`、`combat:tier1`、`homestead:farm`、`production:forging` |
| `useTags` | 用途系统，如 `alchemy`、`forging`、`cooking`、`talisman`、`formation`、`farming`、`beast` |
| `tier` | 材料阶级，用于掉落、品质、图标复杂度和图鉴排序 |
| `visualFamily` | 图标视觉族群，如 `ore-copper`、`wood-thunder`、`fish-dragon` |
| `iconPromptKey` | 给图标生成使用的稳定 key |
| `entersInventory` | 是否进入背包 |
| `status` | `keep`、`rename`、`add_use`、`system_only`、`candidate_remove` |

## 背包归属规则

进入背包：

- 原材料：矿石、宝石、木材、灵草、水产、种子、灵兽副产物。
- 合成基材：例如 `阵基`。
- 战斗材料：后续新增的妖丹、兽骨、残魂等。
- 未开启的奖励包：前提是玩家需要手动打开。

不建议长期作为普通材料进入背包：

- `灵石`：更适合货币账户显示，不适合作为普通材料堆叠。
- `散装药材 / 散装灵矿 / 散装木料 / 散装食材`：更像旧资源折算包，建议做成迁移/补偿系统物品，或领取时自动拆开。
- `鱼宝箱`：如果它只是钓鱼额外奖励，应明确为可打开宝箱；如果没有开箱功能，建议移出材料表。

战斗材料使用原则：

- 普通敌人：掉基础战斗材料，数量少。
- 精英敌人：掉同阶战斗材料，并有概率掉装备/功法。
- 首领敌人：稳定掉同阶核心材料，并有概率掉高阶材料或稀有装备。
- 战斗材料不应该完全替代采集材料，而是和采集材料共同构成配方，让战斗和生活技能互相咬合。

## 需要优先修正的材料

第一优先级：

- `thunderHerb` 与 `thunderSpiritGrass` 同名，建议 `thunderHerb` 改名为“雷纹草”。
- `bloodHerb` 与 `bloodSpiritGrass` 同名，建议 `bloodHerb` 改名为“血藤草”。
- `fishBox`、四类 `Bundle` 需要明确是宝箱、迁移物品还是废弃物。

第二优先级：

- 给宝石系补用途：黄玉、蓝宝、红宝、翠玉、金钻。
- 给中高阶木材补用途：桃木、楠木、梧桐木、血檀、古木。
- 给副产物补用途：树脂、鸟巢、灵桃、灵虫丝、老山参。
- 给锡矿石、秘银矿补配方，避免采矿节点产出无用材料。

第三优先级：

- 给水产扩展料理用途，避免多数鱼只服务于灵兽口粮。
- 把灵石从普通材料体验中逐步拆到货币系统。
- 给每个材料生成来源/用途索引，供 tooltip 展示。

## 图标生成前置规范

图标生成建议使用统一风格：

- 透明背景。
- 适配手游背包格子，48px 下仍能识别轮廓。
- 不要文字，不要 emoji，不要 UI 边框。
- 单个道具居中，轻微俯视或三分之二视角。
- 同一材料族群保持轮廓一致，通过颜色、纹理、发光强度区分阶级。

视觉族群建议：

| 族群 | 统一轮廓 | 区分方式 |
| --- | --- | --- |
| 矿石 | 不规则矿块 | 金属色、矿脉颜色、晶体嵌入 |
| 宝石 | 切面宝石/原石 | 主色、光泽、稀有度光效 |
| 木材 | 木段/枝条 | 树皮纹理、灵光、雷纹/血纹 |
| 灵草 | 单株草药 | 叶形、花/果、灵气颜色 |
| 水产 | 侧向鱼虾轮廓 | 鳞色、触须、雷光/龙纹 |
| 种子 | 种子袋/单颗种子 | 袋子品质、发光强度 |
| 战斗材料 | 爪牙骨血晶 | 暗色冲击感、裂纹、魂火 |
| 系统包 | 包裹/宝箱 | 包材颜色、资源小标识 |
